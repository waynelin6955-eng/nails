05 / CARE NOTES

手足照護資訊，
從觀察與正確求助開始。

以下為一般衛教資訊，不作個別診斷；發現異常時，請交由醫療專業人員評估。

NOTE 01◌

留意持續變化

如果指甲顏色、厚度或外觀持續改變，原因可能不只一種；先記錄變化情形，避免自行判斷或以一般整理代替就醫。

NOTE 02＋

疼痛或紅腫，先詢問醫師

指甲顏色異常持續不退、反覆惡化，或伴隨疼痛、紅腫時，請儘早就醫，由醫師協助評估。

閱讀食藥署衛教資料 ↗
NOTE 03⌁

諮詢前做好紀錄

可簡單記下變化何時開始、是否曾受傷及想詢問的問題，方便與醫療專業人員溝通；不必在網站表單留下健康細節。

本頁提供一般資訊參考，不能取代醫師診斷、治療或個人化醫療建議。本站服務不進行疾病診斷、醫療處置或治療宣稱。

07 / FAQ

常見問題，
先看清楚再決定。

若仍有疑問，請透過官方 LINE 詢問服務者。

服務會替指甲問題作診斷或治療嗎？

不會。本網站介紹的是一般外觀整理與日常照護資訊，不作疾病診斷、治療或醫療處置。若有疼痛、紅腫、傷口或持續變化，請先洽詢醫療專業人員。

可以先了解服務內容再預約嗎？

可以。請先透過官方 LINE 確認服務項目、流程與注意事項，了解後再決定是否安排。實際服務範圍與費用請先向服務者確認。

作品照片會公開嗎？

只會在確認影像使用同意、並妥善處理可識別個人資料後分享。不同意公開不會影響你詢問服務。

如何聯絡或預約？

請由本頁官方 LINE 按鈕聯繫全齡護甲中心；作品與知識分享也可至 Instagram 官方帳號查看。
