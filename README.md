# 好好處理網站

這是可用 GitHub Pages 發布的靜態網站。網站入口是 `index.html`，圖片請與頁面一同上傳。

## GitHub Pages 發布

1. 在 GitHub 建立一個新的 **Public** repository。
2. 上傳這個資料夾內的所有檔案與 `milan-transit.png`。
3. 開啟 repository 的 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選 `main`，資料夾選 `/(root)`，按 **Save**。
6. 等待部署完成，Pages 頁面會顯示網站網址，格式通常為 `https://帳號.github.io/儲存庫名稱/`。

網站會公開在網路上。正式發布前請替換頁面內的示範品牌、價目、聯絡資料及佔位文案。
